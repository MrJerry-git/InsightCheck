# 风险任务卡模板

状态：DRAFT。填完且通过数据核验后才能设为 FROZEN 并开展正式实验。示例中的未来窗口不能当作临床阈值。

| 项目 | 填写内容 |
| --- | --- |
| task_id / version | 待定 |
| 一句话问题 | 用截至何时的哪些资料，预测谁在多长时间内发生什么 |
| 适用人群与排除条件 | 待定 |
| 分析单位 | 受检者 / 病灶；二选一并说明关联方式 |
| 来源与版本 | 官方来源、许可、下载日期、文件哈希 |
| 索引日期 | 如何选取，是否每人多次，是否重叠窗口 |
| 预测窗口 | H 及允许观察范围；依据 |
| 输入清单 | 字段、单位、event_time 与 available_at、缺失策略 |
| 明确禁用字段 | 结局、未来信息、目标检查尚不可用的结果 |
| 阳性定义 | 事件判定、证据字段、时间、专业依据 |
| 阴性定义 | 充分随访要求和未发生依据 |
| 未知与删失 | 缺失随访、竞争事件、无法判定的处理 |
| 病灶关联真值 | 是否存在、来源、复核和争议处理 |
| 样本审计 | 人数、事件数、重复测量、缺失、随访分布 |
| 划分方案 | 患者隔离、时间条件、独立测试锁定 |
| 基线与消融 | 静态 / 静态加纵向；相同样本与划分 |
| 校准与阈值 | 开发集策略，禁止用测试集调节 |
| 下游用途 | 是否进入推荐；折外风险生成策略 |
| 主要指标 | 区分能力、校准、阈值指标与区间 |
| 失效或退出条件 | 标签不可用、阳性不足、模型不适用等 |
| 使用限制 | 来源人群差异、不能支持的结论 |
| 审核记录 | 数据负责人、研究负责人、专业复核、日期 |

标签示例：A 有符合定义的后续事件，可以标 1；B 达到观察要求且无事件，可以按定义标 0；C 没有足够后续记录，应标未知或删失。不能因为 C 的事件表为空就写成 0。
