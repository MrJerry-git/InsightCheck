# 参赛版前端演示与测试资料包

[下载完整 ZIP 资料包](https://github.com/MrJerry-git/InsightCheck/raw/refs/heads/main/docs/competition-test-kit/InsightCheck-frontend-test-kit-2026-09-21.zip)

如果上面的入口未直接下载，打开本目录的 ZIP 文件，再点击 GitHub 的 **Download raw file**。也可以拉取仓库后在本地解压。

## 给组员的使用步骤

1. 更新到最新 `main`，按照仓库 README 安装依赖；已配置环境可运行根目录 `start-smart-import.cmd` 和 `start-competition.cmd`。
2. 打开 `http://127.0.0.1:3030/competition`，确认本地 AI 已就绪。资料包中的 `3040` 和 `D:/junior_fall/...` 是制作机器的隔离预览配置，组员不必照搬。
3. 解压资料包，打开 `00_先读我_使用说明.html`。
4. 先使用 `01_完整演示/B_单年完整资料.txt` 或 `B_单年报告.pdf`，完成导入、核对、点亮、系统详情、整体规划和保存回看。
5. 再使用 A 三年资料展示历史变化；按 `04_操作与验收/前端验收清单.csv` 填写实际测试结果。

## 包含内容

- 三年历史及单年仿真报告：PDF、扫描版 PDF、PNG、JPG、WebP、可复制文字。
- 边界场景：正常血糖、资料过期、当前不适、65岁、缺项与第二轮补充、数值冲突。
- 异常文件：六页超限、超过 8 MB、超过 16000 字、损坏文件、空文件、不支持格式。
- 操作指南、现场演示话术、六组预期结果、26项验收清单、问题反馈模板、文件校验清单。

共33个文件。异常文件故意不能正常导入，不要用于正常演示。

## 真实性与验证范围

全部病例均为人工构造，无真实患者、医院印章或医生签名，不证明医学有效性。测试输入包含病史与用药信息，是为了满足当前接口的完整输入要求，不代表普通检验单天然包含这些字段。

以 2026-09-21 为基准：六组完整病例已调用当前后端核对；B 单年文字及 PDF 已分别通过本地 AI 识别，全部目标字段与仿真设定一致。其他格式和浏览器交互按清单继续验收，不能将预期结果当成全部已通过。

当前 AI 确认流程会把输入标记为“用户确认资料”，不会自动保留仿真分类；演示、截图和视频须主动标注人工仿真。完整对话修改、删除、撤销仍待后续实现。网页打印导出的规划 PDF 也仍需实际验收。

本包是2026-09-21的固定快照。计算日期变化可能改变规划日期与资料时效；请勿把历史预期结果当成永久不变的结论。
