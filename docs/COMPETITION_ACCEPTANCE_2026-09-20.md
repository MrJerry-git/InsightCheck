# 参赛版功能验收（2026-09-20）

> 历史记录归档（2026-09-22）：以下是 2026-09-20 旧版页面的验收记录，不是当前人体地图前端或本批 PR 的验收结论。手动输入、JSON、原文依据等旧交互已被新版设计替代；最新交互与分工以 TASK_WTY_CONVERSATIONAL_IMPORT.md 和 TEAM_TASKS_V2.md 为准。记录中的测试数量、耗时和端口均属于当时环境。

## 结论与范围

本次检查对象是 `/competition` 的心血管体检规划及智能导入闭环，基于 main 的 `695f1e5`，另含本地空白档案性别必填修复。不是整个平台所有侧栏模块或多系统 2.0 的验收。

核心闭环已实际运行：资料输入 → 核对 → PREVENT 风险计算 → 下一年检查建议 → 历史轨迹 → 保存/回看 → JSON 下载。打印/PDF 最终产物未完成验收，因此不应宣称所有输出方式均已通过。

所有本次输入均为人工构造测试资料。功能通过不等于真实患者识别准确率、风险预测准确率或临床推荐有效性已得到验证。

| 空白手动档案 | 浏览器从空白填写日期、数值和病史，生成基础方程报告。缺少血糖资料时提示补齐，没有建议免检。 |

| AI 异常保护 | 自动测试覆盖坏文件、页数限制、模型失败、无效输出、超时、忙碌、必须显式确认和必填完整性。 |

## 尚不能声称已完成的事项

1. PDF 最终输出及分页质量，需要在支持系统打印的浏览器完成实际保存和检查。
2. 真实机构报告、模糊扫描、多页复杂布局及多年份混排的识别质量没有形成代表性评测；AI 必须保留人工核对。
3. 目前没有中国/九华人群效果验证，推荐规则也仍待医学审核。
4. 当前是本机比赛演示版，没有账号隔离与面向公众的完整部署验收。
5. 专门比赛视觉设计（人体示意图/医学插画）以及完整多系统 2.0 不是本次已实现功能的证明。
