## 1. 本轮目标与边界

全平台聚焦同一疾病方向：档案字段、报告解析、趋势、风险、推荐目录、规则、问答和报告使用一致的疾病配置。具体疾病尚未最终选定；肺部方向仅是既有候选，不将其写成已确定的肺癌预测任务。共同字段与通用流程立即实施，疾病专属字段放入版本化配置，待张家睿确定方向后冻结，不由三人各自选择。

“不依赖数据”指不等待九华真实病例，不是完全不用测试样例、项目目录或医学依据。使用明确标注的自制报告、合成病例和测试夹具验证功能；价格与规则分别记录来源，演示内容不得冒充真实内容。

本轮完成所有可独立实现的产品功能、服务连接与运行交付。可以复用现成模型和组件，不要求重新训练 OCR、语言模型或风险模型。模型权重、许可、任务适配和运行条件需要实际核验。配置了可用模型的路径必须真实推理；缺失模型时的明确不可用状态只能算错误处理完成，不能算相应智能功能完成。

暂不安排：合作方数据清洗、自有模型训练与微调、真实效果评估、专家咨询。合作方数据到达并不保证包含随访结局或推荐标签，届时另行审计。原始 CT 检出与分割不在本轮报告解析任务中，也不得宣称已经实现；若最终完整版需要它，应另立明确任务。

## 3. 陈子正：必须完成的前端任务

1. **账户与访问**：登录、退出、当前身份、过期登录处理；按工作人员/审核人员/管理员权限呈现操作，后端仍必须独立鉴权。不开放任意注册管理员。
2. **档案与历史**：档案列表、搜索、新建编辑、详情、手动录入、历史记录查询和纠错；区分用户账户与受检者档案。
3. **导入工作台**：CSV/Excel/PDF/图片上传入口，支持格式和限制说明，解析进度、结果预览、逐字段修改、逐行错误提示、重复导入反馈、确认入库。上传成功不等于入库成功。
4. **趋势页面**：指标选择、实际日期与单位、参考范围来源、历史图表与原始记录联动；处理单点、缺失、异常单位和无历史情况。
5. **影像报告页面**：报告原文与抽取结果对照，病灶列表和变化时间线；人工确认关联、解除错误关联、标记新病灶/待定、撤销与查看修订。不能只有静态展示。
6. **风险页面**：疾病任务、必需信息检查、实际运行入口、加载状态、结果和依据、模型来源及版本；区分不适用、字段不足、运行失败与正常结果，不在前端制造分数。
7. **推荐与预算页面**：三档并列比较，预算输入及重新计算，项目与价格明细、推荐/排除依据、未知价格与冲突。接入真实后端，不能固定提交 standard。
8. **方案审核页面**：增删项目、费用重新计算、规则冲突反馈、修改理由、确认保存、版本对比与历史回看；禁止项目不能通过手动操作绕过后端约束。
9. **报告与问答页面**：完整报告预览与 PDF 下载、历史版本，围绕当前档案/方案问答及来源展示；处理模型未配置、超时、失败，不能将模板冒称大模型回答。
10. **管理页面**：账号角色、体检项目、价格、规则版本和依据、模型可用状态与版本。密钥不进入前端，不显示敏感配置原文。
11. **统一产品体验**：拆分共享大工作台，页面各有明确职责；导航、表单校验、确认提示、加载/空白/失败状态、防重复提交、键盘可操作、桌面和窄屏适配。
12. **接口与验收**：负责全部前端 API 接入，接口未就绪时可用约定夹具开发，交付前替换为真实接口；提供新用户完整流程的浏览器操作证据和问题清单。

完成标准：以上每项均能在页面中操作并影响后端真实状态；刷新、重新登录后结果仍可回看。约 1440px 和 390px 下主要流程可用。按 frontend/AGENTS.md 阅读本地框架文档；运行现有前端测试、lint、类型检查和生产构建。补充覆盖核心交互的测试，不以截图代替联调。

## 4. 王天一：必须完成的业务后端任务

1. **账户和授权**：密码安全存储、登录/退出、会话失效、角色权限、档案访问范围、管理员初始化与账号维护；每个资料/方案/下载入口校验权限，测试跨账号越权。
2. **档案与资料存储**：档案维护、历史查询、来源与修订；文件保存及权限、大小/类型限制、导入任务状态；接王宏锦解析服务，预览与确认入库分开，支持重复检测、事务及失败重试。
3. **分析编排**：把真实历史记录和决策日期交给分析服务，保存运行状态、输入版本与结果；数据修改后标明旧分析需要更新，不把旧结果当新结果。连接风险、排序和规则结果。
4. **三档方案正式接入**：复用已有 plan_builder 和价格模块，接入工作流 API 与快照，提供三档、预算、机构/地区、排除项和冲突；取消硬编码未知费用和单一档位路径。
5. **方案编辑与审核**：项目增删、重新执行规则和费用计算、审核权限、确认/撤回或修订状态、修改理由与版本；保存事务及重复请求幂等，保留旧方案可读性。
6. **管理 API**：项目、价格来源与生效时间、规则草稿/启用/版本及证据、模型状态、审计记录。规则配置不能为空却显示通过；示例规则标明用途。
7. **报告和问答入口**：完整方案快照的报告查询及中文 PDF 下载，包含来源、版本、未知项与修订；接王宏锦问答服务并校验档案访问权限，保存必要的问答引用信息。
8. **运行交付**：迁移链、配置示例、一键启动/停止与部署说明、依赖健康检查、日志和错误定位、备份恢复、持久文件存储；对外部署配置包括 HTTPS/反向代理及正确跨域和会话设置。提供本地验证，云部署如缺服务器单独列明，不能虚报已上线。
9. **联合集成**：负责公共工作流编排、接口文档和可运行的整体后端，主动与陈子正完成页面联调，不以纯服务测试通过结束。

完成标准：实际 API 可操作全部业务；新增权限、上传、幂等、快照和迁移测试通过；三档服务确实被线上请求调用；验证备份恢复后档案与方案一致。PDF 中文可读且与已保存方案一致。不得提交病例、数据库、密钥或权重到普通 Git 历史。

## 5. 王宏锦：必须完成的解析、分析与模型服务任务

1. **统一资料契约**：定义报告、指标、病灶、来源、事件日期、可获得日期、修订状态；与王天一对齐存储格式，与陈子正提供逐字段错误及原文定位信息。疾病专属字段配置化。
2. **表格导入与标准化**：CSV/Excel 解析、列映射、名称和单位归一、缺失/重复/冲突检查，保留原值；不能无依据转换单位。提供自制标准模板与错误样例。
3. **PDF/图片解析**：评估并接入可运行的现成文档解析/OCR 组件；文本 PDF 与扫描件分别处理，抽取结果返回页码/原文位置及待核对状态。明确至少一组支持的报告版式，使用自制报告验证；不承诺任意版式。
4. **报告结构化与病灶关联**：抽取疾病相关字段，复用或完善历史病灶匹配服务，提供候选、理由和待复核状态；支持应用人工纠正后重新分析，不把无法关联当作新发或消失。
5. **纵向分析服务**：按真实日期计算变化，处理测量缺失与单位问题；提供风险/推荐共用特征和前端图表数据。禁止使用决策日期后才获得的记录。
6. **各类模型复用评估与接入**：覆盖 OCR/抽取、病灶文本表示或匹配、风险、推荐排序、问答解释。先判断是否需要模型，能用确定性逻辑可靠处理的部分不强加模型；每个候选记录代码/权重、许可、输入预处理、预测目标、硬件、运行验证和替换方式。优先核验最适合候选，失配即换路线，不无限等待数据。
7. **统一模型适配器**：按任务分别定义输入输出、版本、适用性和错误，不用单一概率冒充不同任务。兼容现有风险制品接口；LightGBM/DeepFM 保留可接入路径。排序必须兼容本平台项目编码，不直接使用外部物品 ID。
8. **真实问答服务**：接入可配置语言模型，使用当前档案、方案及有版本的依据生成解释并返回引用；回答不能改写计算结果或直接写入方案，找不到依据时明确说明。外部服务地址与密钥由环境配置，测试用合成资料，调用成本/凭据需求提前提出。
9. **真实数据到达前的接入准备**：提供字段映射配置、数据质量摘要工具、训练数据导出契约和模型更换说明，不预设九华一定提供标签、随访或图片。

完成标准：交付可调用服务与示例，OCR/解析/趋势/病灶/问答分别实际运行验证；模型有权重不等于适配成功。风险或排序若无兼容模型，完成适配工程后将“真实推理未完成”单独列出，不以 stub、假分数或合成制品覆盖状态。没有真实样本时只报告功能测试，不声称真实识别率或推荐效果。

## 7. 联合验收与最终版本状态
