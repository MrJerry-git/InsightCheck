# 公开数据选型与过渡计划

核验日期：2026-09-16。合作方数据尚未取得。本次核实官方目录与访问说明；未完成实际文件下载、字段统计或模型训练。

## 推荐顺序

| 来源 | 现在的用途 | 不能证明的内容 | 访问状态 |
| --- | --- | --- | --- |
| Synthea | 合成历史记录导入、时间线、接口、方案联调 | 真实风险准确率、真实推荐质量；不保证存在结节轨迹 | 官方提供 CSV 小样本，优先下载 |
| NLST 公开临床子集 | 优先审计肺部筛查纵向研究可行性 | 通用体检套餐适宜性、中国人群外部有效性 | NCI 确认 IDC/TCIA 有公开子集；字段覆盖待查 |
| NLST 完整临床数据 | 公开子集不足时的研究申请备选 | 尚未获批不能称为已拥有 | CDAS 需要项目审批与数据协议 |
| NHANES | 标准化、横断面表格基线候选 | 不能直接验证同一人历年病灶变化或未来进展 | 官方公开调查数据；按具体周期核查 |
| MIMIC-IV | 后期必要时研究真实事件流 | 不等价于健康体检人群与项目适宜性 | 需要认证、培训、数据使用协议；暂不优先 |

选择不是寻找一个“替代全部合作方数据”的万能数据集，而是让工程、风险实验与推荐评价各有合适证据。不能把这些来源拼成虚构患者。

## Synthea 获取与验收

官方 [下载页](https://synthetichealth.github.io/downloads.html)提供 100 人 CSV 样例，页面标注约 7 MB。直接入口：[CSV ZIP](https://synthetichealth.github.io/synthea-sample-data/downloads/latest/synthea_sample_data_csv_latest.zip)。latest 会变化，下载时必须记录日期和 SHA256，不能仅写 latest。

验收：确认 ZIP 有效；列出文件与字段；统计实际患者数和各表行数；检查时间和关联键；依据实际字典映射患者、就诊、观测、检查行为；所有结果标记 synthetic。官方允许这些合成数据广泛使用，仍应保留引用来源。

不能把住院/处置统一转换为体检项目；不导入无用的姓名、地址等仿真身份字段。没有病灶数据时使用独立合成病灶夹具测试，并明确它不是 Synthea 原生的真实病灶随访。

## NLST 获取与可行性审计

[NCI CDAS 官方目录](https://cdas.cancer.gov/datasets/nlst/)确认有公开临床子集，并提供 [IDC 官方访问教程](https://github.com/ImagingDataCommons/IDC-Tutorials/blob/master/notebooks/collections_demos/nlst_clinical_data.ipynb)。完整数据须提交项目申请，不能把公开字典当作已获得完整数据。

目录包含筛查、异常、比较阅片、诊断操作及结局等不同表。这使 NLST 成为优先审计候选，但不证明公开子集已经足够。先看临床字段，不批量下载 CT 影像。

审计问题：能否按人连接多轮筛查？日期是绝对日期还是相对时间？哪些结局有明确观察窗口？比较阅片信息是否可得？是否有可靠病灶身份或只到检查级？能否构造阳性、阴性、未知，而不把未复查当作阴性？

分支：字段完整时冻结相应任务卡；只有受检者级结局时，不宣称完成病灶级轨迹验证；关键字段缺失时申请完整数据或记录任务不可行。官方页面内容和许可要随实际取得文件再次核对。

[TCIA 集合页](https://www.cancerimagingarchive.net/collection/nlst/)搜索索引显示有临床数据与字典下载；本次正文读取失败，因此尚未核验该下载包内容和可用字段。

## NHANES 和 MIMIC 的边界

[NHANES 2017—2018 官方数据目录](https://wwwn.cdc.gov/nchs/nhanes/continuousnhanes/default.aspx?BeginYear=2017)可用于查看检查、问卷与实验室数据。[CDC](https://www.cdc.gov/nchs/nhanes/visualization/)明确它是横断面调查。不同周期不是同一人随访；调查权重、分层和抽样设计应依据分析目标处理。若定义当次异常分类，要排除直接构成标签的同次指标，不能包装成未来风险预测。

[MIMIC 官方访问说明](https://mimic.mit.edu/docs/faq/how-to-get-access.html)说明访问需要培训及协议；[PhysioNet FAQ](https://physionet.org/about/faqs/)说明受限数据使用者需分别获得权限。当前项目无需为赶进度绕过访问要求，也不优先承担住院场景迁移成本。

## 必须产出的数据文件

Git 中保存：适配代码、下载说明、许可引用、字段映射、无个体信息的质量报告、任务卡模板。

本地忽略目录保存：原始文件、转换表、患者级划分、模型、预测结果。数据清单应记录校验和与版本；对清单内的路径和标识做公开适宜性检查。

当前没有找到并核验能直接提供“通用体检项目适宜性真值”的开放数据。推荐部分先做规则与合成工程验证，真实评价需要后续专家核验方案或适合的独立标注，不能拿规则生成标签再宣称优于同一套规则。
